# podcast-feed

Personal podcast feed of AI-generated audio overviews (scripts by Claude, voices by Gemini TTS).

- Feed: https://tengs-fan.github.io/podcast-feed/feed.xml
- Add an episode: `python3 publish.py episode.mp3 --title "..." --description "..."`, then commit and push.

GitHub Pages must be enabled for this repository (Settings → Pages → Deploy from a branch → `main`, `/ (root)`).
